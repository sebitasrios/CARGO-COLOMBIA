# CARGO-DATA COLOMBIA

Landing page de un proyecto formativo sobre el transporte de carga en Colombia. Combina análisis de datos, un tablero interactivo y una calculadora de rutas.

> **Proyecto académico:** la empresa es ficticia, y algunos datos provienen de fuentes públicas de referencia usadas para completar el contenido.

## Objetivo

Construir una landing page completa que integre análisis de datos y herramientas interactivas, trabajando en equipo con la metodología Scrum.

## Qué incluye

- Análisis de datos hecho con Python
- Tablero interactivo con Looker Studio
- Calculadora de tiempo y distancia con mapa (Google Maps)
- Páginas de inicio, análisis, contacto y formularios

## Tecnologías

HTML5, CSS3, JavaScript, Bootstrap 5, Google Maps, Looker Studio y Python.

## Equipo

Equipo de tres personas con los roles de Product Owner, Scrum Master y Development Team.

- **Sebastián Ríos Ríos:** Development Team. Diseño, construcción e implementación de las funcionalidades.

## Cómo verlo

Es un sitio estático: abre `index.html` en el navegador o usa la extensión Live Server de VS Code.
